# MyPortfolio

A simple student portfolio website created using HTML and CSS.

## Project Structure

```text
MyPortfolio/
├── README.md
└── StudentProfile/
    ├── index.html
    └── style.css
```

## How to View
1. Open the `StudentProfile` folder.
2. Open `index.html` in your web browser.

## Customize
Replace the sample name, course, and section in `StudentProfile/index.html` with your own information.
